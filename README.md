
MSc in Statistics at ETH Zürich. Interested in **statistical inference, multi-fidelity modelling, uncertainty quantification, trustworthy AI, and scientific machine learning**.

## Research & Recent Work

- **Multi-Fidelity Statistical Data Fusion (Research Paper)** — Developed a robust multi-fidelity framework for combining data sources of varying quality, with applications to citizen-science air pollution modelling.
- **Exoplanet Atmospheric Inversion** — Statistical and machine learning approaches to atmospheric retrieval, using surrogate models and physical simulations to tackle computationally expensive inverse problems.
- **Satellite Radiance Reconstruction (CLARA / ERA5)** — Spatio-temporal Gaussian processes for reconstructing missing satellite observations using atmospheric reanalysis data, with an emphasis on uncertainty quantification.
- **LLM Watermark Detection (ETH SRI, ongoing)** — Research on statistically rigorous detection of localised watermarked text, exploring sequential testing and reliable inference.
- **Disaster Risk Reduction (UNDRR)** — Investigated damage-data availability, quality, and reliability for machine learning applications in disaster risk assessment.

## Other Selected Projects

- **Evolutionary Game Theory Models** — Simulation-based exploration of strategic population dynamics.
- **Waiting Times in Healthcare (PHS Operational Research)** — Probability-driven modelling and statistical computation for healthcare systems.
